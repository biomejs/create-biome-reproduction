# @biomejs/create-biome-reproduction

CLI for generating minimal reproduction repositories for Biome issues.

## Usage

You can initialize a minimal reproduction template using your favorite package manager:

```bash
# Using npm
npm create @biomejs/reproduction

# Using npx
npx @biomejs/create-biome-reproduction

# Using pnpm
pnpm create @biomejs/reproduction

# Using bun
bun create @biomejs/reproduction
